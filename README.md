## Study and work with the music

[Composition-to-code guide](COMPOSITION-TO-CODE.md) · [Composition template](templates/new-composition/README.md) · [Warm Fog](tracks/04-next-composition/README.md)

The [TypeScript arrangement tool](music-code/README.md) works from note events. Water Glints includes a Logic project, PDF and MusicXML scores, MIDI, and synthesis source files. The earlier recordings include cards for entering notes; audio alone is not treated as a verified transcription.

Warm Fog includes project documentation and listening links for Cycles I, II, and III. Cycle III’s Jam Code workshop has a short passport; its TypeScript collaboration layer and complete Logic package are not yet published. The Cycle II Logic package is also pending.

The three repository MP3s can be played and downloaded. See [code licensing](CODE-LICENSE.md) for the files covered by MIT. A separate licence for adapting or commercially using the music, recordings, scores, Logic projects, or artwork has not been granted. Detailed project notes are currently in Russian.

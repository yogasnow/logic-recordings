# Logic Recordings

Музыкальные произведения Снежаны, созданные в Logic Pro. У каждого трека — своя папка с аудио (когда оно есть) и краткой карточкой для будущего авторского разбора. Это отдельный проект, не часть [Live Coding](https://github.com/yogasnow/live-coding).

**Учебный маршрут:** [доска «Учёба и вклад»](https://github.com/users/yogasnow/projects/1) → [задача №1: water glints](https://github.com/yogasnow/logic-recordings/issues/1) → [паспорт произведения](tracks/03-water-glints/README.md) → авторская проверка → музыкальный код. Доска показывает состояние работы; файлы и версии хранятся в этом репозитории.

В карточках оставлены поля для авторского объяснения: форма, размер и ритм, знаки альтерации, гармония и аккорды по тактам. Пока нет партитуры или проекта Logic, эти музыкальные решения не утверждаются по одному MP3.

Два доступных MP3 можно слушать и скачать; отдельная лицензия на переработку или коммерческое использование не предоставлена. Проектные файлы Logic и партитуры не опубликованы. GitHub не заменяет Logic Pro: изменение звуков и инструментов будет возможно после получения исходного проекта и открытия его в Logic.

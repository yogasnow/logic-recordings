# Аранжировка по нотам · TypeScript

Это учебный инструмент для создания редактируемого MIDI из **нотных событий**, а не автоматическое извлечение нот из MP3. [Код доступен по лицензии MIT](../CODE-LICENSE.md); права на музыкальное содержание и аудио определяются отдельно. Исходные музыкальные решения остаются за автором; любой учащийся может изменить назначение тембров и сделать собственную аранжировку.

Нужен Node.js 24 или новее. В корне проекта:

```bash
node music-code/arrange.ts tracks/03-water-glints/music-code/score.json water-glints-piano.mid piano
node music-code/arrange.ts tracks/03-water-glints/music-code/score.json water-glints-strings.mid strings
```

У Water Glints входом служат [подтверждённые события редакции](../tracks/03-water-glints/data/events.json). Скрипт сохраняет их высоту и время, но заменяет звуки стандартными General MIDI-инструментами. **Это учебные MIDI-аранжировки, не оригинальный рендер и не точная реконструкция тембров Logic.** Ударные используют MIDI-канал 10; в чужом проигрывателе их тембр может отличаться.

## Как работать с двумя ранними мелодиями

У [Am Dialogue](../tracks/01-am-dialogue/score.json) и [Velvet and Sky](../tracks/02-velvet-and-sky/score.json) пока доступны MP3, но нет проверенных нотных событий, MIDI или партитуры. Их `score.json` намеренно пусты: код не выдаёт догадку за авторскую мелодию. Когда появятся исходные ноты, добавьте темп и события в формате:

```json
{"start": 0, "duration": 1, "pitch": 60, "velocity": 80, "voice": "melody"}
```

`start` и `duration` измеряются в четвертных долях; `pitch` — номер MIDI-ноты (60 = до первой октавы); `voice` — партия. Затем запустите тот же `arrange.ts` с соответствующим `score.json`. Сначала сверяйте ноты с авторской партитурой, затем меняйте тембры в `programs` и сравнивайте звучание. Для точного переноса многоголосной партитуры нужны её MIDI/MusicXML или проверенная ручная запись каждой партии.

## Учебный шаг

Сгенерируйте обе версии Water Glints, откройте MIDI в нотном редакторе или Logic и сравните партии. Затем измените **один** тембр в `programs`, повторите запуск и опишите, что изменилось, не меняя высоту и ритм нот.

# Исходный проект Logic · water glints

**Статус:** файл проекта Logic ещё не получен. Здесь будет лежать проверенная исходная версия, чтобы Снежана могла открыть её в Logic, менять инструменты, звуки и аранжировку. GitHub хранит версии, но не редактирует звук в браузере.

Перед загрузкой сверяем название и дату версии, размер файла, входящие аудиофайлы/сэмплы и зависимости от плагинов. Не включаем в открытый репозиторий лицензированные библиотеки, чужие сэмплы или приватные файлы по умолчанию. Если проект нельзя публиковать целиком, оставим здесь точный манифест и разместим только разрешённые экспортированные материалы.

Пока для произведения нет ни проекта Logic, ни MP3-экспорта. [Паспорт произведения](../README.md) указывает только подтверждённые данные.

# Проект Logic Pro — Атастин / Water Glints

[Скачать ZIP проекта](https://github.com/yogasnow/logic-recordings/releases/download/atastin-logic-v1/Atastin-Logic-Only.zip) — 110.2 МБ. Распакуйте и откройте `Atastin - 64 - Editable.logicx` в Logic Pro.

Внутри 11 непустых аудиослоёв и 10 MIDI-дорожек; WAV встроены, MIDI по умолчанию приглушены. При работе с MIDI отключайте соответствующий аудиослой, чтобы избежать удвоения. Тембры штатных патчей отличаются от процедурного рендера; проверяйте октавную компенсацию басовых MIDI-регионов при смене патча.

[Полный паспорт и файлы](../README.md). Проект находится в Release этого репозитория; здесь хранится точная ссылка, без второй тяжёлой копии ZIP в Git-истории.

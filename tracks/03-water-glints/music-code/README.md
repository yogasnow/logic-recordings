# Музыкальный код

Исходники получены: [синтез Python](../source/render_audio.py), [события](../data/events.json), [карта тактов](../data/bars.json), [карта рендера](../data/render-map.json), [MIDI](../scores/Atastin-64-Editable.mid).

Рендер был создан кодом и затем перенесён в Logic. Нотная редакция и исходные MIDI-события различаются округлением длительностей для чтения; подробности в [паспорте](../README.md#границы-точности). Для запуска синтеза нужны Python 3 и numpy.

## TypeScript-аранжировка

[Учебный инструмент](../../../music-code/README.md) читает [подтверждённые события](../data/events.json) через [карточку партитуры](score.json) и создаёт редактируемый MIDI с выбором тембров. Он сохраняет высоту и время событий, но не повторяет звук оригинального рендера.

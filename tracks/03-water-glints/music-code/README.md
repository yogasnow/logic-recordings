# Следующий шаг: музыкальный код

Цель — выразить **подтверждённые** музыкальные данные произведения в структуре, которую можно воспроизвести и изменить.

1. Из авторского паспорта перенести темп, размер, последовательность частей и тактов в данные.
2. Добавить ноты, длительности, паузы, знаки альтерации и аккорды по тактам.
3. Написать небольшой проверяемый генератор MIDI/аудио рядом с данными, сравнить результат с авторским экспортом.
4. Документировать расхождения и править их вместе с автором, не выдавая кодовую версию за оригинальную запись Logic.

**Статус:** пока нет исходной партитуры или точной карты тактов, поэтому код музыкальной последовательности не создаём наугад. [Учебная задача](https://github.com/yogasnow/logic-recordings/issues/1) собирает необходимые источники.

## Авторский музыкальный разбор

Здесь последовательно собираем **вводные данные → форму → ритм → мелодию и альтерации → гармонию по тактам → характер и динамику**. Сначала переносим исходные авторские данные, затем сверяем их с экспортом и проектом Logic. Если версии различаются, отмечаем версию и дату, а не смешиваем сведения.

| Раздел | Что зафиксировать |
| --- | --- |
| Темп и размер | BPM, размер, смены темпа/размера и такты, где они происходят |
| Форма | Вступление, части, переходы, повторения и их диапазоны тактов |
| Ритм | Пульс, длительности, паузы, синкопы и повторяющиеся фигуры |
| Мелодия | Основной мотив, развитие, ноты и знаки альтерации |
| Гармония | Аккорд или гармоническая функция по тактам; точная запись аккордов автора |
| Характер и динамика | Авторские слова о настроении, громкости, нарастании и спаде |
| Звук | Инструменты, тембры и приёмы в проекте Logic, если они подтверждены |

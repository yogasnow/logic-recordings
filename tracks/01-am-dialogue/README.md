## Открытая аранжировка

[Карточка нотных событий](score.json) подготовлена для [TypeScript-инструмента](../../music-code/README.md). Пока доступен только MP3, поэтому исходные ноты и код мелодии не заявлены как восстановленные. Для точной учебной аранжировки нужен исходный MIDI/MusicXML, проект Logic или проверенная нотная запись. После их получения можно заполнить партии и менять тембры, сохраняя авторскую мелодию.

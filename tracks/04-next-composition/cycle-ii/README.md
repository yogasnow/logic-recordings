# Warm Fog · Cycle II

[Слушать Warm Fog · Cycle II на SoundCloud](https://soundcloud.com/karmasnow/warm-fog-cycle-ii)

Здесь слушатель слышит готовую запись: обложка, описание, комментарии и возможность делиться ссылкой. SoundCloud — витрина звучания; совместное редактирование Logic-проекта или TypeScript-кода там не предусмотрено.

Ссылка и описание предоставлены автором 31 октября 2026. Это отдельный второй цикл произведения Warm Fog.

## GitHub — рабочая мастерская

[Logic Recordings на GitHub](https://github.com/yogasnow/logic-recordings) — место для паспорта трека, исходного кода аранжировки, MIDI/MusicXML, инструкций для Logic и ссылок на SoundCloud.

Сейчас для Cycle II доступны эта Markdown-карточка, ссылка на SoundCloud и ссылка на общий сохранённый паспорт Warm Fog с оговоркой о соответствии версии. Исходный код аранжировки, MIDI/MusicXML и полный Logic-проект **именно Cycle II пока не выгружены**. Их можно добавить после проверки сохранённых материалов.

Музыканты могут изучать доступные файлы и предлагать изменения через fork/pull request. Создание и распространение собственных вариантов музыки и проекта возможно только в пределах явно указанной применимой лицензии; публичный доступ сам по себе такого разрешения не даёт.

Markdown-документы репозитория можно открыть в Obsidian как папку заметок. ZIP Logic-проекта — отдельный пакет для Logic Pro, а не Markdown-vault; Obsidian не заменяет редактор проекта или аудио.

## Паспорт и сохранённый проект

[Сохранённый паспорт Warm Fog от 30 октября — PDF](../Warm-Fog-Project-Passport-2026-10-30.pdf) описывает три редакции: Voice Lead, Voice Ensemble и Instrumental. Соответствие одной из этих редакций **Cycle II пока не подтверждено**. Поэтому параметры и технические измерения из этого PDF не приписываются записи Cycle II автоматически.

Полный сохранённый Logic-проект Cycle II в репозиторий пока **не добавлен**. Для полной выгрузки нужен авторский пакет `.logicx` или ZIP с включёнными используемыми аудиозаписями и сопутствующими файлами проекта. Комплектность и соответствие публикации предстоит проверить перед загрузкой. Сторонние установщики, плагины, библиотеки сэмплов и секретные данные в поставку не входят.

Репозиторий публичный. Отдельная лицензия на повторное использование музыки, записей и Logic-проекта пока не предоставлена. [MIT для учебного кода](../../../CODE-LICENSE.md) применяется только к перечисленным в ней исходным файлам и автоматически на эти материалы не распространяется.
